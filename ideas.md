# Stark AI Portfolio — Design Plan

## Chosen Approach: Dark Neon Tech Portfolio (Reference Match)

This site matches the design pattern from https://mido685.github.io/stark-ai-portfolio/ — a dark-themed, cyan-glowing AI portfolio.

## Design Philosophy
Dark neon tech portfolio with deep navy background, bright cyan/teal accents, glowing effects, and structured single-page scroll layout. Conveys cutting-edge AI expertise with professional futuristic feel.

## Color Palette
- Background: `#0a0e1a` (very dark navy)
- Cards: `#111827` with cyan border glow
- Primary accent: `#00d4aa` (bright cyan/teal)
- Text primary: `#ffffff` (white)
- Text secondary: `#9ca3af` (light gray)
- Glow: `box-shadow: 0 0 15px rgba(0, 212, 170, 0.3)`

## Typography
- Headings: Bold, large, cyan with text-shadow glow
- Body: Clean sans-serif, white
- Tech labels: Monospace, uppercase

## Layout (Single Page Scroll)
1. **Hero** — Full viewport, logo, "STARK AI" + subtitle + 3 CTAs
2. **About** — Two-column: description + founder card; 6 skill cards
3. **Projects** — 3 project cards with screenshots, stars, tech tags, actions
4. **Technologies** — Grid of tech icons with labels
5. **Architecture** — Flow diagram
6. **Testimonials** — Client quote cards
7. **Blog** — Article cards with search/filter
8. **Contact** — Contact info + form
9. **Footer** — Social links + copyright

## Key Elements
- Cyan glow on headings and active nav
- Card borders with cyan glow
- Pill-shaped tech tags
- Star ratings
- Smooth scroll nav
- Scroll-to-top button
- Fixed navbar

## Brand Essence
"STARK AI — Intelligent Systems that Turn Data Into Decisions"
Personality: Technical, Innovative, Professional
